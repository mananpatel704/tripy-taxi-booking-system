# Tripy - Taxi Booking System

Tripy is a web-based taxi booking system developed using PHP and MySQL.  
This project allows users to book taxis online and allows admin to manage bookings, drivers, and users.

## Features

User Panel:
- User registration and login
- Book taxi online
- View booking history
- Search available rides

Admin Panel:
- Admin login
- Manage drivers
- Manage users
- Manage bookings
- View booking details

## Technologies Used

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- PHP (Core PHP)
  

Database:
- MySQL

Server:
- XAMPP (Apache + MySQL)

## Project Structure

tripy/
- admin/
- css/
- js/
- uploads/
- index.php
- config.php
- database/tripy.sql

## Database Setup

1. Open phpMyAdmin
2. Create a new database called:

tripy_db

3. Import the file:

database/tripy.sql

4. Database connection settings are in:

config.php

Example configuration:

localhost  
username: root  
password: (blank)

## Installation Steps

1. Install XAMPP
2. Move the project folder to:

xampp/htdocs/

3. Start Apache and MySQL
4. Open browser and run:

http://localhost/tripy
